What is the ABC Interactive Learning System?
It is a fun, web-based educational game designed for children to learn their alphabet letters, practice how to write them, and play interactive games using physical objects and a smartphone or tablet camera.

How Does it Work? (The User Journey)
Step 1: The Twin QR Scan Challenge
Children start by scanning a QR code on a physical object (like a block or a card) using their device's camera.

Next, they scan a second QR code to try and find its matching pair.

Step 2: Instant Smart Feedback
The system checks if the two scans match and responds instantly:

🎉 If they MATCH (Success!): * A happy sound plays, and a voice congratulates them.

The screen pops up a beautiful digital flashcard of that letter.

It unlocks special buttons: an external interactive learning link and a "How to Write" screen that shows them the exact tracing strokes for both uppercase and lowercase versions of that letter.

😢 If they DO NOT match: * A gentle "try again" sound plays to keep them encouraged.

To keep them smiling and learning, a special bonus button appears that lets them watch a fun "ABCs Alphabet Song" video.

Step 3: A Seamless Experience (Smart Memory)
When children are done watching a video or practicing writing, they can press the "⬅ Kembali" (Back) button.

Thanks to a built-in memory feature, the system instantly remembers their exact scan results. They won't get lost or have to start over from scratch—they can simply pick up right where they left off!

Key Features Behind the Scenes
Child-Friendly Audio & Speech: The app talks directly to the children, using friendly text-to-speech technology to guide them through their learning journey.

Fun Mini-Games Included: It features a dedicated "Alphabet Match" dashboard filled with exciting touch-screen mini-games (like balloon popping and tracking games) to reinforce what they've learned.

No App Install Required: It runs entirely inside a standard web browser, making it incredibly fast and easy to open on any phone or tablet with a camera.
